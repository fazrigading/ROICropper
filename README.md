# ROICropper
- ROI Cropper: Crop image(s) object from a file or folder to 1:1 ratio.
- ROI Cropper: Crop objek dalam gambar dari file atau folder menjadi gambar dengan rasio 1:1.

# Usage
```
python ROICropper.py -i path/to/image/file/folder -o path/to/output/file/folder -s 640 -p 5
python ROICropper.py --input path/to/image/file/folder --output path/to/output/file/folder --size 1280 --padding 10
```
- Size (Default: 640)
- Padding (Default: 10)
